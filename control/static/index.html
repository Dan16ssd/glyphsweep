How the agent works

Nothing is trusted. Everything is measured.

01 · planScope

Validates the URL and builds a per-job egress allowlist.

02 · dispatchSandbox render

Chromium in gVisor runs deterministic detectors on real glyph ink.

03 · bare deviceTofu → number

Re-renders with no script font; OCR measures what a phone shows.

04 · verifyVision check

A vision model on Vultr confirms what a reader actually sees.

05 · fixSanitized CSS

The model writes a patch and translations; a sanitizer strips anything risky.

06 · proveFresh sandbox

Patches compete in new sandboxes. Only the best measured one ships.
